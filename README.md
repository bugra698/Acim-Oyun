# 🎮 Acim Oyun

Python ve Ursina Engine kullanılarak geliştirilmiş, içinde RTX teknolojisini taklit eden **ışın izleme (Ray Tracing)** ve DLSS teknolojisini taklit eden bir **kare arttırıcı** barındıran 3D oyun projesi.

## 🚀 Nasıl Çalıştırılır?

Oyunu bilgisayarınızda sorunsuz bir şekilde çalıştırmak için aşağıdaki adımları sırasıyla uygulayın:

### 1. Projeyi Bilgisayarınıza İndirin
Sağ üstteki yeşil **Code** butonuna tıklayıp **Download ZIP** diyerek projeyi indirin ve bir klasöre çıkartın. 

*(Alternatif olarak Git kullanıyorsanız şu komutla klonlayabilirsiniz):*
```bash
git clone https://github.com
cd Acim-Oyun
```

### 2. Gerekli Kütüphaneleri Yükleyin
Bu oyun **Ursina (Panda3D)** motorunu kullanmaktadır. Klasörün içinde bir terminal (CMD) açın ve şu komutu yazarak gerekli tüm bağımlılıkları otomatik olarak yükleyin:
```bash
pip install -r requirements.txt
```

### 3. Oyunu Başlatın
Kütüphaneler yüklendikten sonra oyunu başlatmak için terminale şu komutu yazın:
```bash
python main.py
```

## 🛠️ Özellikler
* **Yapay Işın İzleme (RTX Mimic):** Python üzerinde ışık ve gölge simülasyonu.
* **Kare Arttırıcı (DLSS Mimic):** Performansı optimize eden dinamik kare ölçekleme çözümü.
* **Ursina & Panda3D:** Güçlü ve optimize edilmiş 3D grafik motoru altyapısı.
